# Architecture

The browser serves HTML, CSS and vanilla JavaScript from `public/` and calls the Express API over the same origin. `server/app.js` enforces sessions, CSRF, role and class access, validation, daily version conflicts and report calculations. `server/db.js` opens SQLite, applies the idempotent schema/migrations and enables foreign keys, WAL and a busy timeout. `server/index.js` starts one process. The path is `DB_PATH`, defaulting to `data/attendance.sqlite`.

Persistent records include accounts, classes and assignments, students and inclusive enrollment intervals, calendar exceptions, settings, attendance, class/date versions and correction audit. A transaction validates the entire submission before saving. SQLite constraints and enrollment guards complement server validation. Saved corrections record actor, UTC timestamp, reason, previous and new values; the daily version rejects stale submissions. A correction to a stored value requires a reason, including a change to Unmarked. See [API](API.md) and [backend details](backend-notes.md) for request shapes and error behavior.

Admin can manage classes, accounts, assignments, students, enrollment, calendar and threshold. Faculty access is scoped to assigned classes. Passwords are hashed and sessions are held in server memory; restarting invalidates sessions. CSRF tokens are required for mutations, including login, and the token rotates on login. Protect transport with HTTPS when deploying outside a local isolated demonstration. CSV and the on-screen report use the same calculation service, and exported cells are protected against spreadsheet formulas.

The Docker image runs as a non-root user with the database on a writable volume. Kubernetes uses a single replica and `Recreate` with a PVC: SQLite on this design is not suitable for multiple writers across replicas. Jenkins is configured for checkout, locked install, tests, build, registry publication, an isolated test deployment and browser validation. These are configuration artifacts, not evidence of a successful external deployment.
